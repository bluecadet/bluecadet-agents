# Bluecadet House Glossary

Terms confirmed from available project context. Add to this file whenever a new term gets confirmed with a human, in the same format, keep it alphabetical within each section.

## Teams & practice areas

- **Experiential** — one of Bluecadet's two core practice areas: interactive installations and digital experiences.
- **Web** — the other core practice area: large-scale website strategy, design, and development.

## Internal deliverables & codenames

- **Basecadet** — Bluecadet's productized base Drupal template, meant to speed up new project starts. **Mars Landing** is the internal project codename used while it's being built (Basecadet 1.0 is Mars Landing's deliverable).

## Conventions

- **`80_agents`** — a subfolder convention inside a project's Google Drive folder, used to hold AI-agent working files (meeting summaries, decision logs) for that project. A project without this folder hasn't been set up for agent-based workflows yet.
- **`bc_` / `bluecadet_` module prefix** — naming convention for Bluecadet's shared, cross-project custom Drupal modules (e.g. `bc_api_base`, `bluecadet_utilities`, `bluecadet_file_structure`), distinct from a client project's own one-off custom modules.

## Standard agency terms (not Bluecadet-specific, but used constantly)

- **SOW** — Statement of Work.
- **ROM** — Rough Order of Magnitude (an early, non-binding estimate).
- **multidev** — a Pantheon hosting platform feature: an isolated, deployable environment for a specific branch, distinct from dev/test/live.
